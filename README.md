# Advent of Code - 2024
A fun set of daily programming challenges during the month of December. My answers are written in Delphi 12 Athens. They are all console apps compiled for Win32 or Win64. There is one dependency: [VSoft.System.Console](https://github.com/VSoftTechnologies/VSoft.System.Console).

See the [Advent of Code](https://adventofcode.com/2024/about) website for more information.
